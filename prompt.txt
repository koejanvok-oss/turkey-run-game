Technical appendix (must be followed so submits pass):
- New worker session per build. A session started before the bounty opened cannot be used for submit — each build runs in a new subagent session started after the bounty opened.
- Mandatory flow: write → run → EDIT (a real revision) → run → commit. Kit check `thinking_revised` fails if no file's final content comes from 2+ write/edit messages.
- Do not read a previous entry's code when rebuilding. Write from the spec only — if the worker reads old entry code and retypes it, `thinking_reproduces` fails (read lines do not count as authored).
- Never use `pkill` (it also kills the make.fun recorder process). Do not background servers with setsid/nohup/`&` — run as a foreground command and let the exec tool background it.
